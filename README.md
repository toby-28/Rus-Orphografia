## 🇷🇺 Rus-Orphografia

A lightweight TypeScript-based tool for analyzing and correcting Russian orthography. Designed for educational use, linguistic experimentation, and potential integration into larger language processing pipelines.

### ✨ Features
- Tokenizes and analyzes Russian text for orthographic patterns
- Highlights potential spelling inconsistencies
- Modular structure for easy extension and integration
- Tailwind CSS for clean UI (if frontend is included)

### 🚀 Getting Started

#### Prerequisites
- Node.js ≥ 18
- npm or yarn
- TypeScript

#### Installation
```bash
git clone https://github.com/toby-28/Rus-Orphografia.git
cd Rus-Orphografia
npm install
```

#### Run the App
```bash
npm run dev
```

#### Build for Production
```bash
npm run build
```

### 🧪 Testing
If you plan to add tests:
```bash
npm run test
```
